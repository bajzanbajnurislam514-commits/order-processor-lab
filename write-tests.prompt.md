description: Генерация pytest unit-тестов с parametrize для граничных случаев и некорректных данных
---
Напиши unit-тесты на `pytest` для выбранного модуля в каталоге `tests/`.

Требования:
- Используй `@pytest.mark.parametrize` для всех найденных граничных случаев и
  некорректных входных данных (пустые значения, 0, отрицательные, выход за диапазон,
  отсутствующие поля, неверный формат).
- Ошибки валидации проверяй через `pytest.raises(OrderValidationError)`.
- Добавь тест на «счастливый путь» и проверку, что `print()` не используется.
- Для работы с БД используй `tmp_path`, не трогай реальные файлы.
- Аннотации типов обязательны для всех тестовых функций.
- Не изменяй исходный код модуля и существующие тесты.
- В конце запусти `pytest` и `ruff check .` и сообщи результат.
